## 🌟 About This Repository

This repository contains a collection of mini-projects and assignments designed to strengthen core **Java** and **OOP** skills. Each project addresses real-world logic building, encapsulation, inheritance, polymorphism, and array manipulations.

## 🚀 Assignments Overview

### 🎓 1. Student Profile & Calculator
*Located in: `StudentProfile/`*
* **Description**: A basic profile generator and calculator.
* **Key Concepts**: Formatted output, basic arithmetic operations, and type casting.

### 🍔 2. Food Delivery Rating Analyzer
*Located in: `FoodDeliveryRating/`*
* **Description**: Analyzes delivery partner and restaurant ratings.
* **Key Concepts**: Method overloading (handling 1D and 2D arrays), aggregate calculations.

### 🏫 3. Student Activity Management System
*Located in: `StudentActivity/`*
* **Description**: Terminal-based menu application for tracking attendance.
* **Key Concepts**: Control flow (switch-case), conditional logic, terminal UI.

### 📊 4. Student Marks Management System
*Located in: `StudentMarks/`*
* **Description**: Multi-subject mark analyzer.
* **Key Concepts**: 2D Arrays, linear searching, and bubble sorting algorithms.

### 🏨 5. Hotel Room Booking System
*Located in: `HotelBooking/`*
* **Description**: Simulates a dynamic hotel booking interface.
* **Key Concepts**: Encapsulation (getters/setters), constructors (`this` keyword), static counters for tracking total bookings.

### 🚗 6. Vehicle Rental Management System
*Located in: `VehicleRental/`*
* **Description**: A scalable vehicle rental platform.
* **Key Concepts**: Inheritance (`extends`), method overriding, abstract characteristics, subclass-specific property mapping.

## 🛠️ How to Compile & Run

<div align="center">
  <img src="https://media.giphy.com/media/M9gbBd9nbDrOTu1Mqx/giphy.gif" width="300" alt="Terminal Command"/>
</div>

Navigate to the repository root directory in your terminal and use the following commands:

**1️⃣ Compile all files:**
```bash
javac */*.java
```

**2️⃣ Run a specific assignment:** *(Example: Vehicle Rental System)*
```bash
java VehicleRental.VehicleRentalSystem
```
